# Skills

The `basix` meta-skill documents how to maintain this collection. It intentionally contains no scraping, mirroring, or other domain workflow. Basix skills keep technical content in English and produce user-facing chat messages in the language of the current conversation.

The `basix-agent-authoring` skill plans, creates, and updates native agent TOMLs. It classifies work as Simple, Medium, Complex, or Highly complex and applies the corresponding Luna `low`, `medium`, `high`, or `max` reasoning default. Highly complex work includes demanding development, difficult source-code verification, bug hunting and repair, and multi-stage planning with subagent coordination; `basix_pager` and `basix_verifier` are canonical examples. The skill inserts the managed native bootstrap and validates that each agent loads the router-owned Contract 1.3 before planning or domain work without embedding a second contract copy. It retains the JSON Schema and validates message streams, including requested-report announcements, automatic continuation after intermediate reports, and optional final-result `subagent_insights`. An adjacent sandbox marker permits `workspace-write` only for `basix_pager`; every other native agent remains read-only.

Add each future workflow under `skills/<name>/SKILL.md` with a specific trigger description. Put its scripts, references, and assets in that skill directory. Put only launchers shared by multiple skills or agents under top-level `scripts/`.
