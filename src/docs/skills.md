# Skills

The `basix` meta-skill documents how to maintain this collection. It intentionally contains no scraping, mirroring, or other domain workflow. Basix skills keep technical content in English and produce user-facing chat messages in the language of the current conversation.

The `basix-agent-authoring` skill plans, creates, and updates native agent TOMLs. It keeps two independent axes: task complexity selects Luna reasoning effort, while agent level (`junior`, `senior`, or `principal`) selects coordination and spawn authority. Every native TOML begins with validated commented metadata; persistent native principals require an explicit user request and marker. Juniors spawn nobody, seniors only the native explorer and researcher, and non-root principals never another principal. The skill inserts the managed native bootstrap and validates that each agent loads the router-owned Contract 1.4 before planning or domain work without embedding a second contract copy. It retains the JSON Schema and validates message streams. An adjacent sandbox marker permits `workspace-write` only for `basix_pager`; every other native agent remains read-only.

The `basix-experience` skill writes a localized, evidence-based Markdown retrospective when a user requests feedback about the current session, used skills, subagents, or token efficiency. It excludes itself from evaluation and reports only visibly evidenced use. Exact input, reasoning, output, and cache figures require supplied structured telemetry; missing values remain explicitly unavailable, while visible workflow costs receive qualitative analysis and five ranked saving opportunities.

Add each future workflow under `skills/<name>/SKILL.md` with a specific trigger description. Put its scripts, references, and assets in that skill directory. Put only launchers shared by multiple skills or agents under top-level `scripts/`.
