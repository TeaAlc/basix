# ADR 0001: Plan phase tasks and learnings

## Status
Active

## Context
Saved plans must distinguish planned work from validated later findings.

## Decision
Each phase has Goal, Work with Task 1 through Task n, QS, and an empty Learnings field. Populate Learnings only after successful QS with findings relevant to later phases.

## Consequences
Plans expose execution order and carry forward only validated, useful findings.
